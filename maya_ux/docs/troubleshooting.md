# 문제 해결

## 버튼이 회색이다 / 눌러도 실행되지 않는다

마우스를 올려 툴팁 맨 아래 ⚠ 줄을 확인하세요. 대표 원인:

| 메시지 | 해결 |
|---|---|
| `Edit Mode(Mesh) 에서 사용할 수 있습니다` | Tab 으로 Edit Mode 진입 후 실행 (Extrude/Bevel/Inset/Loop Cut 등) |
| `현재 선택/모드에서는 실행할 수 없습니다 (poll 실패)` | 대상 오브젝트를 선택했는지, 올바른 종류(메시/아마추어)인지 확인 |
| `'xxx' 확장이 설치/활성화되어 있지 않습니다` | Get Extensions 에서 해당 확장 설치·활성화 후 진단 패널의 **다시 검사** |
| `명령 … 이(가) 없습니다. 'xxx' 확장 버전이 바뀌었을 수 있습니다` | 확장 업데이트로 Operator ID 가 바뀜. ✎ 로 버튼 대상을 다시 지정 |
| `Graph Editor 영역이 현재 화면에 없습니다` | 버튼의 실행 영역이 Graph Editor 인 경우, 화면에 그 편집기를 열어 두세요 |
| `프로퍼티가 맞지 않습니다` | ✎ 편집에서 프로퍼티(JSON) 이름/값 확인 |
| 스크립트: `신뢰 확인이 필요합니다` | Preferences 에서 스크립트 버튼 허용 → ✎ 에서 코드 미리보기 확인 후 `신뢰` 체크 |
| 스크립트: `신뢰한 뒤 파일 내용이 바뀌었습니다` | 내용 변경 감지(SHA-256). 다시 확인 후 신뢰 |

진단 패널(사이드바 > MayaUX > 진단)에 사용할 수 없는 버튼과 이유가 모여 있습니다.

## 단축키가 안 먹는다

1. Preferences > MayaUX > 단축키에서 해당 항목 상태 확인
   * `충돌 - 기존 유지`: 다른 단축키가 우선합니다. `대체` 를 누르거나 ↵ 로 다른 키를 지정
   * `OS 예약키`: 운영체제가 먼저 가로채는 키. 다른 키 지정
   * `명령 없음`: 이 Blender 버전에 해당 Operator 가 없음
2. 키맵 프리셋을 바꿨다면 **다시 검사**
3. 다른 애드온이 같은 키를 쓰면 충돌 설명에 `다른 애드온` 으로 표시됩니다

## 기존 단축키가 사라졌다

`대체` 를 고른 항목은 원래 단축키를 **삭제하지 않고 끄기만** 합니다. 단축키 탭에서 `복원`, 또는 `모두 기존 유지`,
또는 확장을 비활성화하면 되살아납니다. 기록은 `local.json` 의 `deactivated` 에 있습니다.

## 설정 파일이 깨졌다

읽을 수 없는 설정 파일은 `<이름>.json.broken` 으로 옮겨 보존하고 기본값으로 시작합니다. 진단 패널에 메시지가 표시됩니다.

## 가져오기 오류

* `JSON 형식 오류 (줄 n, 칸 m)` — 파일 편집 중 문법 오류
* `더 새로운 MayaUX(schema n)` — 확장을 업데이트하세요
* 잘못된 버튼/탭은 건너뛰고 미리보기의 `건너뛴 항목` 에 나열됩니다

## 개발자용: 테스트

```bash
pip install pytest
python -m pytest maya_ux/tests                 # bpy 없이: 모델/스키마/충돌 분석 테스트
pip install bpy pytest                         # Blender 버전에 맞는 bpy (4.5 → Python 3.11)
python -m pytest maya_ux/tests                 # + 실제 Blender 통합 테스트 (IC 키맵 충돌, 애드온 호환, 실행)
python maya_ux/tests/report_keymap.py          # 단축키 비교표 재생성
```
