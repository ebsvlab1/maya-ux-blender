# 단축키 참조 (Phase 0 비교표)

MayaUX 의 키맵은 **Blender Industry Compatible(IC)** 키맵을 기준선으로 하고, Maya 와 다른 부분만 추가합니다.
아래 표는 실제 IC 키맵 데이터에 대해 MayaUX 충돌 분석기를 돌려 **자동 생성**한 결과입니다
(`python maya_ux/tests/report_keymap.py`, bpy 필요). Blender 버전이 바뀌면 다시 생성하세요.

상태 뜻

| 상태 | 의미 |
|---|---|
| ✅ IC 그대로 | IC 에 이미 같은 동작이 있어 MayaUX 는 아무것도 등록하지 않음. Blender 기본 키맵을 쓰는 경우에는 MayaUX 가 보완 등록 |
| ➕ MayaUX 추가 | 충돌 없는 키라 MayaUX 가 등록 |
| ⚠️ 충돌 | 같은 키를 IC 가 다른 용도로 사용. 기본은 **기존 유지**(등록 안 함). Preferences > MayaUX > 단축키에서 항목별로 `대체` 선택 가능, `복원` 으로 언제든 되돌림 |

요약 (Blender 5.2 IC 기준 분석, 4.5 LTS 의 IC 데이터와 동일 키 사용 — 4.5 에서 재생성 권장)

* **그대로 사용 가능한 키**: Q/W/E/R, Alt+LMB/MMB/RMB, F, A, Ctrl+D, S, Shift+W/E/R, Space, G, P, B, 1/2/3, Graph/Dope Sheet 의 F/A/S
* **커스텀 구현(추가)한 키**: 6/7 셰이딩, =/- 매니퓰레이터 크기, Insert 피벗 편집, F8~F11 컴포넌트 전환, Shift+./, 선택 확장·축소, Shift+Z 다시 실행, Alt+./, 프레임 이동, Ctrl+Space 최대화
* **충돌로 사용자 결정이 필요한 키**: 4/5 (IC: 모드 전환), Z (IC: 영역 확대), . / , (IC: 피벗·좌표계 파이)

## Maya 와 다르게 남는 부분 (의도적으로 바꾸지 않음)

| Maya | 이유 / Blender 대안 |
|---|---|
| Ctrl+G 그룹 | Blender 에는 Maya 그룹 노드가 없음. IC 의 Ctrl+G 는 컬렉션 이동. 빈 오브젝트(Empty)에 페어런트하는 방식 사용 |
| Ctrl+A Attribute Editor | IC 에서 Ctrl+A 는 전체 선택. N 사이드바 / Properties 편집기 사용 |
| D(홀드) 피벗 편집 | Blender 는 키 '홀드' 바인딩이 없음 → Insert 토글로 대체 |
| Space(홀드) Hotbox | Space 재생과 충돌. Hotbox 메뉴는 Ctrl+Shift+Space 옵션(기본 꺼짐) 또는 Shelf 헤더 팝오버로 제공 |
| Ctrl+H / Shift+H 숨기기 | IC: Ctrl+H 숨기기, Alt+H 보이기, Shift+H 나머지 숨기기. Maya 의 '마지막 숨긴 것 보이기' 개념 없음 |
| 1/2/3 스무스 미리보기 | IC 는 1/2/3 을 컴포넌트 선택 모드로 사용 (PRD 4.1 결정 유지) |

## 플랫폼

* **macOS**: Ctrl+Space(입력 소스), Cmd+Space/H/Q/M/W 등은 OS 예약키로 자동 제외되어 `OS 예약키` 로 표시됩니다.
  Preferences > MayaUX 에서 `Ctrl 단축키를 Cmd 로 등록` 을 켜면 Ctrl 조합을 Cmd 로 등록합니다.
* **Windows**: Alt+F4/Tab/Space, Win 키 조합은 제외됩니다.
* **Linux**: GNOME/KDE 등 일부 창 관리자가 Alt+드래그를 창 이동에 사용합니다. 시스템 설정에서 창 이동 수정 키를 Super 로 바꾸세요.
